# Simple Calculator

A lightweight calculator application built with Python's tkinter library.

## Features

- **Basic Arithmetic**: Supports addition (+), subtraction (-), multiplication (*), and division (/)
- **Decimal Support**: Perform calculations with decimal numbers
- **Clear Function**: Reset the calculator with the C button or press Escape
- **Backspace**: Delete the last character with the ⌫ button or press Backspace
- **Keyboard Support**: 
  - Number keys (0-9) for digit input
  - Operator keys (+, -, *, /) for operations
  - Enter to evaluate
  - Backspace to delete the last character
  - Escape to clear
- **Error Handling**: Shows "Error" for invalid expressions
- **Colorful GUI**: Clean, modern interface with intuitive button layout

## Requirements

- Python 3.x
- tkinter (usually included with Python)

## Running the Calculator

```bash
python3 calculator/calculator.py
```

The calculator window will open. You can use either the GUI buttons or your keyboard to perform calculations.

## Usage Examples

- **Simple Addition**: Click 5 + 3 = (or type 5+3 and press Enter)
- **Decimal Calculation**: 10.5 * 2 =
- **Clear**: Press C or Escape to reset
- **Backspace**: Press ⌫ or Backspace to delete the last entry
